# Графика и звук без внешних программ

Справочник для агентов. Графического редактора и звуковой студии у проекта нет, поэтому
всё делается текстом и кодом.

> **Проверено на Godot 4.7.2 (2026-11-07).**
> - Импорт SVG и пиксели после растеризации проверены.
> - Все шейдеры из `examples/shaders/` компилируются; сломанный шейдер компиляцию
>   роняет. Как собирается `COLOR`, сверено по исходнику шейдера в бинарнике.
> - Звуки из `examples/sfx_synth.gd` собираются; генератор переживает `halt()` →
>   `start()` и `freq = INF`.
> - Вид на телефоне headless не показывает: смотри скриншотом и на устройстве.

**Сначала столпы.** Стиль игры — цветная анимация 1930-х; сцены статичные (анти-столп
«NOT озвучка и анимированные сцены»), а музыка и звуки — уровень Full Vision в
`design/gdd/systems-index.md`. Удары, взрывы и вода ниже — общие приёмы. В этой игре
они нужны точечно: бросок d20, критический успех или провал, переход между сценами,
эффект старой плёнки. Не повторяй узнаваемый стиль конкретной существующей игры: только
общий стиль эпохи.

## а) SVG: иконки и спрайты текстом

Godot растеризует SVG один раз, при импорте (ThorVG). Проверено на 4.7.2:

| Возможность SVG | Результат в 4.7.2 |
|---|---|
| `path`, `circle`, `rect rx`, `stroke`, `linecap/linejoin` | работает |
| `linearGradient` (и радиальный по той же схеме) | работает |
| `<style>` с классами CSS | работает |
| `mask` | работает |
| `filter` с `feGaussianBlur` | работает (размытие видно) |
| **`<text>`** | **молча не рисуется** (0 непрозрачных пикселей) |

Правила:

- **Текст в SVG не пиши.** Буквы — кривыми (`path`), а надписи интерфейса — нодой
  `Label` или `RichTextLabel`: они масштабируются, переводятся и читаются экранным
  диктором.
- **Размер.** `width` / `height` = размер в пикселях при базовой ширине окна 1080. Для
  чёткости на плотных экранах поднимай `svg/scale` в `.import` (по умолчанию `1.0`), а
  не размер в самом SVG.
- **Стиль 1930-х.**
  - Толстый тёмный контур (`stroke-width` 4–8 при 64–256 px).
  - `stroke-linecap="round"`, `stroke-linejoin="round"`.
  - Плоская заливка 2–4 цветами плюс один градиент на объём.
  - Палитра «старой бумаги»: тёплый жёлтый, кирпичный, тёмно-коричневый вместо
    чёрного.
- **Без внешних ссылок.** Никаких `href` на файлы или шрифты: ThorVG их не подтянет.
- **Проверка.**
  - `godot --headless --path . --import` — в логе не должно быть ошибок по файлу.
  - Глазами — скриншот (`.claude/docs/run-and-observe.md`).
  - Иллюстрации сцен (не иконки) делаются по арт-библии, когда она появится (`/art-bible`).

```svg
<svg xmlns="http://www.w3.org/2000/svg" width="64" height="64" viewBox="0 0 64 64">
  <circle cx="32" cy="32" r="28" fill="#e8b04a" stroke="#1a1410" stroke-width="4"/>
  <path d="M20 34 L30 44 L46 22" fill="none" stroke="#1a1410" stroke-width="6"
        stroke-linecap="round" stroke-linejoin="round"/>
</svg>
```

## б) 2D-шейдеры (`.gdshader`)

Готовые шейдеры в `examples/shaders/`. Имена — по `.claude/rules/shader-code.md`
(`[тип]_[категория]_[имя]`). У каждого файла шапка: назначение, автор, целевой
рендерер и бюджет.

| Файл | Эффект | Бюджет | Чем анимировать |
|---|---|---|---|
| `canvas_fx_hit_flash.gdshader` | вспышка удара или урона: спрайт уходит в цвет | 0 доп. выборок | Tween `flash` 1 → 0 за 0,15 с |
| `canvas_fx_outline_glow.gdshader` | свечение или обводка вокруг непрозрачных пикселей, с пульсом | 8 выборок — только спрайт | `TIME` внутри; `radius_px` |
| `canvas_fx_water_wave.gdshader` | вода, жар, «сон» — волна UV | 1 выборка | `TIME` внутри |
| `canvas_fx_drop_shadow.gdshader` | плоская мультяшная тень от силуэта | 1 доп. выборка | `offset_px` |
| `post_screen_old_film.gdshader` | **старая плёнка**: зерно, виньетка, мерцание, царапины | 1 полноэкранный проход | `TIME` внутри |

Правила:

- **`COLOR` во `fragment()` уже содержит текстуру.** Проверено по канвас-шейдеру
  рендерера Compatibility, встроенному в бинарник 4.7.2:
  - до кода пользователя выполняется `color = color_interp`, затем
    `color *= texture(color_texture, uv)`;
  - `modulate` входит в цвет ещё на этапе вершин (`color_attrib * modulation`).

  Поэтому `texture(TEXTURE, UV) * COLOR` накладывает текстуру **дважды**: картинка
  темнеет, альфа уходит в квадрат.
  - Берёшь цвет пикселя — читай `COLOR`.
  - Нужна выборка в другой точке (соседи для свечения и тени, искажённый UV для
    воды) — `texture(TEXTURE, …)`.
  - Цвет вершины с `modulate` передавай в `fragment()` через `varying` из `vertex()`.
    Так сделано в `canvas_fx_water_wave`. У свечения, тени и плёнки через него же идёт
    альфа: невидимый спрайт не оставляет силуэта, слой плёнки плавно включается через
    `modulate:a`.
- **Рендерер — Compatibility** (OpenGL 3.3 / ES 3; `project.godot`, `modules/rendering.md`).
  - Пиши простой `canvas_item`: без `compute`, без 3D, без выборок в циклах.
  - Для цвета — `mediump`, для хэшей с большими множителями — `highp`.
  - Фазу сворачивай через `mod(TIME * speed, 2π)`, а не голый `TIME`: так нет скачка, и
    `sin()` на телефонных GPU не теряет точность.
- **Полноэкранный слой** (`post_screen_old_film`) — шейдер на `ColorRect`:
  - а) слой — лист без детей: последний ребёнок корня экрана или отдельный
    `CanvasLayer` над интерфейсом;
  - б) у самой `ColorRect` **и у каждой Control-обёртки вокруг неё**
    `mouse_filter = 2` (IGNORE), иначе обёртка со STOP съест все нажатия;
  - в) IGNORE нельзя ставить на родителей кнопок: в 4.5+ выключение ввода может
    распространяться на потомков (`modules/ui.md`).

  `hint_screen_texture` читает уже нарисованный кадр, с `filter_linear` — без цепочки
  mip-уровней. Слой перерисовывается каждый кадр, пока идёт `TIME`. Поэтому:
  - его выключает настройка «меньше анимации», это же запасной уровень для слабых
    телефонов;
  - кадр замеряй на слабом устройстве (`/perf-profile`);
  - сила по умолчанию низкая (зерно 0,05, виньетка 0,35, царапины 0,1), потому что слой
    лежит поверх основного текста. Проверь контраст шапки и нижнего варианта
    скриншотом.
- **Прозрачный запас.** Свечению и тени нужны прозрачные поля вокруг спрайта, иначе
  эффект обрежется по краю текстуры.
- **Проверка компиляции headless:** загрузи шейдер и спроси список параметров. Ошибка
  синтаксиса печатает `SHADER ERROR` с номером строки, а список приходит пустым.

  ```gdscript
  var sh := load("res://src/fx/post_screen_old_film.gdshader") as Shader
  print(sh.get_shader_uniform_list().map(func(u): return u.name))
  ```

  Компилируется — ещё не значит «так выглядит на Mali или Adreno»: смотри скриншотом и
  на устройстве.

## в) Звук кодом, без `.wav`

Два способа (оба в `examples/`):

1. **Запечь → `AudioStreamWAV`** (`examples/sfx_synth.gd`, класс `SfxSynth`). **По
   умолчанию для коротких звуков.**
   - Готовые функции: щелчок интерфейса `click`, глухой удар `thud`, ретро-взрыв `boom`,
     перестук кубика `dice_rattle`.
   - Звук считается в `PackedFloat32Array` и кладётся в 16-битный PCM
     (`AudioStreamWAV.FORMAT_16_BITS`, 22 050 Гц, моно).
   - Запекание — цикл GDScript по каждой выборке, десятки тысяч на набор звуков.
     Поэтому **запекай при загрузке и кэшируй**, никогда в момент события, иначе
     рывок придётся ровно на бросок.
   - Для разнообразия (перестук кубика) заранее запеки 3–4 варианта с разными зёрнами и
     выбирай при событии.
   - Случайность только через `RandomNumberGenerator` с зерном: звук повторяем, его
     можно проверить тестом.
   - Нулевая длина даёт пустой поток, `hits = 0` — тишину (проверено): не «чини» их
     через `max(n, 1)`, получишь 0/0.
2. **Синтез в реальном времени → `AudioStreamGenerator`** (`examples/sfx_stream.gd`).
   Только для непрерывного звука, который меняется по ходу игры (гул, высота тона за
   прогрессом).
   - **Управление только через `start()` / `halt()`**, не через `play()` / `stop()`, и
     `stream` не переназначать. Проверено в 4.7.2: каждый `play()` создаёт **новый**
     playback, а после `stop()` старый мёртв. `start()` берёт его заново, `halt()`
     выключает и обработку кадра.
   - Буфер на 512 кадров выделен один раз, за кадр пишется не больше 32 таких блоков. Генератор держит 0,25 с: это переживает
     подвисание главного потока (синхронная загрузка), а смена высоты тона отстаёт не
     больше чем на 0,25 с.
   - `freq` с NaN или INF (деление у вызывающего) не портит фазу: значение зажимается,
     проверено.
   - Больше одного-двух таких потоков не запускай: GDScript считает каждую выборку на
     CPU телефона.

Как звучит в 1930-х: короткие щелчки и бум без ревербации; бой барабана и «вжух» —
перепадом высоты (`thud` с f0 → f1). Громкость — через шину (`AudioServer`), а не числами
в коде. Звуковой системы в проекте ещё нет: громкость и шины решит её GDD.
