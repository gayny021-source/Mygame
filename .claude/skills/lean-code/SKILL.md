# lean-code — хирургический минимальный код

Выжимка `andrej-karpathy-skills` и `ponytail` под Godot 4.7.2 / GDScript.

## 1. До правки

- Назвать допущения. Неясно или два прочтения — спросить, не выбирать молча.
- Есть путь проще — сказать. Задача вредит — возразить.
- Найти всё, до чего дотянется правка: вызовы (`graphify query`, `Grep`), тесты, сцены,
  `project.godot`, ресурсы `.tres`, сохранения.
- Цель — проверяемая: «баг» → «тест воспроизводит, потом проходит».

## 2. Наименьшая полная правка (первый подходящий вариант)

1. Нужно ли это вообще? Лишнее не делать, назвать одной строкой.
2. Уже есть в проекте (хелпер, сцена, паттерн)? Взять так же, как рядом.
3. Есть в движке (`Tween`, сигналы, `Resource`, `RandomNumberGenerator`)? Взять. API — только из
   `docs/engine-reference/godot/`.
4. Одна понятная строка? Одна строка.
5. Иначе — минимальный рабочий код.

## 3. Запреты

- Нет фич, опций, конфигов и «на будущее», которых не просили.
- Нет абстракций, обёрток, базовых классов и синглтонов под один вызов.
- Нет обработки невозможных случаев. Есть проверка на границах доверия: данные сцен, файлы
  сохранений, ввод.
- 200 строк, а можно 50 — переписать.

## 4. Хирургия

- Трогать только нужное. Соседний код, форматирование и комментарии не «улучшать».
- Стиль файла сохранять: статическая типизация, `snake_case`, сигналы — `Callable`.
- Чужой мёртвый код — назвать, не удалять. Свои сироты (переменные, функции, ресурсы) — убрать.
- Баг — найти всех вызывающих, чинить корень в общем месте, один раз.
- Перенесённый код сохраняет свои проверки и обработку ошибок.
- Комментарий — только «почему», одной строкой. Срезал угол — `# shortcut: <предел>, <когда менять>`.

## 5. GDScript 4 по минимуму

- `@onready` и `%Unique` вместо длинных путей `get_node`. `await` только с защитой от
  удалённой ноды (`is_instance_valid`).
- Числа баланса — в данных, не в коде. Случайность — через внедряемый источник (тесты).
- Управление касанием и `mouse_filter` — по `.claude/skills/tscn-handcrafter/SKILL.md`.

## 6. Перед коммитом

- Граничные случаи: пустые и нулевые данные, двойное касание, сворачивание и выгрузка Android,
  смена размера окна, повтор после загрузки.
- Прогнать `commands.test`, сцену — `godot-scene-check.gd`. Без проверки правка не готова.
- Каждая изменённая строка прослеживается до задачи. Иначе — откатить лишнее.
