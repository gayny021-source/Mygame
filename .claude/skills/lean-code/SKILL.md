# lean-code — Lean & Typed Code Standard (GDScript 4, Godot 4.7.2)

Выжимка `andrej-karpathy-skills` и `ponytail`. Компактно, типизированно, без потери скорости на Android.

## 1. YAGNI & No Boilerplate

- Писать ровно тот код, который нужен задаче. Нет заготовок, опций и конфигов «на будущее».
- Нет классов-обёрток, базовых классов и синглтонов под один вызов; нет геттеров и сеттеров без логики.
- Нет комментариев к очевидному. Комментарий — только «почему», одной строкой; doc-комментарий — у публичного API.
- Сначала искать готовое: хелпер проекта, затем движок. Свой код — последним.
- Нет обработки невозможного: узел из `@onready` и `%Unique` существует — `if node:` и `is_instance_valid` на нём не нужны.
- Проверки остаются на границах доверия: данные сцен, файлы сохранений, ввод, нода после `await`.
- Неясно или два прочтения — спросить. 200 строк, а можно 50 — переписать.

## 2. Typed Compactness

- Строгая статическая типизация везде, она ускоряет мобильный рантайм: `var speed: float = 100.0`, `func hit(dmg: int) -> void:`.
- Типизировать коллекции, сигналы и циклы: `Array[int]`, `signal hit(dmg: int)`, `for id: StringName in ids:`. `:=` — только когда тип виден из правой части.
- Ранний выход вместо вложенности: `if not valid: return`.
- Встроенное вместо ручного: `clampf`, `move_toward`, `lerpf`, `create_tween()`, сигналы, `Resource`. API — только из `docs/engine-reference/godot/`.
- `@onready` и `@export` вместо `get_node` в методах; в `_process` нет аллокаций и поиска нод.
- Числа баланса — в данных, не в коде. Случайность — через внедряемый источник (тесты).

## 3. Edit-Friendly Formatting

- Не склеивать независимые команды через `;`. Одна логическая операция — одна строка.
- Нет пустых строк-разделителей внутри функции; между функциями — как в файле.
- Однострочник допустим только для раннего выхода. Длинное выражение разбить на именованные шаги.

## 4. Surgical Changes

- Менять только затронутые строки. Соседние рабочие функции, форматирование и комментарии не переписывать и не «улучшать».
- Стиль файла сохранять. Чужой мёртвый код — назвать, не удалять. Свои сироты (переменные, функции, ресурсы) — убрать.
- Баг — найти всех вызывающих (`graphify query`, `Grep`), чинить корень один раз. Перенесённый код сохраняет свои проверки.
- Срезал угол — `# shortcut: <предел>, <когда менять>`.

## 5. Перед коммитом

- Граничные случаи: пустые данные, двойное касание, сворачивание и выгрузка Android, смена размера окна, повтор после загрузки.
- Прогнать `commands.test`, сцену — `godot-scene-check.gd`. Без проверки правка не готова.
- Каждая изменённая строка прослеживается до задачи. Иначе — откатить лишнее.
